FOS_List

The FOS_List module provides a generic singly-linked list with a tail pointer. Each node stores one element in separately allocated storage.

The list supports insertion and removal at both ends, indexed access, element replacement, traversal, reversal, and stable merge sort.

There are two files:

  • FOS_List.h is the public header intended to be included by user code.
  • FOS_List.c contains the implementation and is included in source distributions.

FOS_List representation invariants

For every successfully initialized FOS_List:

  • elem_size > 0

  • size equals the number of nodes in the list

  • if size == 0:

    • head == NULL
    • tail == NULL

  • if size > 0:

    • head != NULL
    • tail != NULL
    • tail->next == NULL

For every node:

  • data != NULL
  • data points to a buffer of at least elem_size bytes
  • next is either NULL or points to another node in the same list

Starting at head and following next pointers reaches every node in the list exactly once, with tail being the final node.

The list owns all nodes and the element buffers stored in those nodes. Items supplied to insertion functions are copied into list-owned storage.

Element representation and copying

FOS_List is generic and stores elements as raw byte sequences of elem_size bytes.

Insertion and replacement operations copy exactly elem_size bytes from the supplied object into list-owned storage.

The list does not interpret the contents of stored elements.

Consequently, if an element contains pointers or other resources, the list copies those values but does not manage the resources they refer to.

The caller is responsible for ensuring that the supplied objects are valid for reading for elem_size bytes and that copying their object representations is appropriate for the intended use.

Insertion and removal

FOS_list_push_front() and FOS_list_push_back() insert an element at the corresponding end of the list.

Because the list maintains both head and tail pointers, insertion at either end is O(1).

FOS_list_pop_front() removes the first element and is O(1).

FOS_list_pop_back() removes the last element, but must traverse the list to find its predecessor because the list is singly linked. Its complexity is O(n).

FOS_list_remove_at() removes an element by position. It must traverse the list to locate the node and is therefore O(n) in the general case.

When an output pointer is supplied to a removal operation, the removed element is copied into the caller's buffer before its storage is released.

Indexed access

The list provides two forms of indexed access.

FOS_list_at() returns a pointer to the element at the specified position without modifying the list.

FOS_list_at_mut() returns a mutable pointer to the element at the specified position.

Positions are zero-based:

position 0   -> first element
position 1   -> second element
...
position size - 1 -> last element

Indexed access is O(n) because nodes must be traversed from head.

The returned pointer refers to storage owned by the list and becomes invalid when the corresponding node is removed or when the list is freed.

Front and back access

FOS_list_front() returns a pointer to the first element.

FOS_list_back() returns a pointer to the last element.

Because the list maintains a tail pointer, both operations are O(1).

The returned pointers refer to list-owned storage and must not be freed by the caller.

Reversal

FOS_list_reverse() reverses the links between nodes in place.

No element data is copied and no additional node storage is allocated.

After reversal:

  • the former head becomes the new tail;
  • the former tail becomes the new head;
  • tail->next == NULL;
  • size and elem_size are unchanged.

The operation is O(n).

Sorting

FOS_list_sort() sorts the list using a user-supplied comparison function.

The implementation uses stable merge sort.

Merge sort operates directly on the linked nodes by rearranging their next pointers. It does not allocate new list nodes or copy element data.

If two elements compare equal, the element that appeared earlier in the original list remains earlier in the sorted list.

The sorting algorithm has:

time:  O(n log n)
space: O(log n) auxiliary stack space

apart from the list nodes and element storage already owned by the list.

The list's head pointer is updated after sorting, and the tail pointer is recomputed so that the representation invariants remain satisfied.

A list containing zero or one element is already sorted and requires no changes.

Traversal

FOS_list_foreach() visits every element from head to tail.

The callback receives a const pointer to each element and therefore cannot modify the element through that pointer.

FOS_list_foreach_mut() provides mutable access to each element.

Both functions traverse the list in O(n) time.

The user argument is passed unchanged to every callback and can be used to provide caller-defined context.

List lifetime

FOS_list_init() initializes an empty list for elements of elem_size bytes.

On successful initialization:

  • head == NULL
  • tail == NULL
  • size == 0
  • elem_size is set to the supplied element size

FOS_list_free() releases all nodes and all element buffers owned by the list, then resets the list to an empty, uninitialized state:

  • head == NULL
  • tail == NULL
  • size == 0
  • elem_size == 0

After FOS_list_free(), the list may be initialized again.

Functions

bool FOS_list_init(FOS_List *list, size_t elem_size);

Initializes an empty list for elements of elem_size bytes.

elem_size must be nonzero.

Returns true on success and false if list is NULL or elem_size is zero.

bool FOS_list_push_front(FOS_List *list, const void *item);

Copies elem_size bytes from item into a newly allocated node and inserts the node at the beginning of the list.

Updates head, tail, and size as necessary.

Returns true on success and false if the arguments are invalid or memory allocation fails.

bool FOS_list_push_back(FOS_List *list, const void *item);

Copies elem_size bytes from item into a newly allocated node and inserts the node at the end of the list.

Updates head, tail, and size as necessary.

Insertion is O(1) because the list maintains a tail pointer.

Returns true on success and false if the arguments are invalid or memory allocation fails.

bool FOS_list_pop_front(FOS_List *list, void *out);

Removes the first element of the list.

If out is not NULL, the removed element is copied into the buffer it points to.

Updates head, tail, and size and releases the removed node and its element storage.

Returns true on success and false if the list is NULL or empty.

bool FOS_list_pop_back(FOS_List *list, void *out);

Removes the last element of the list.

If out is not NULL, the removed element is copied into the buffer it points to.

The operation traverses the list to locate the predecessor of the tail and has O(n) complexity.

Returns true on success and false if the list is NULL or empty.

bool FOS_list_is_empty(const FOS_List *list);

Checks whether the list contains no elements.

Returns true if list is NULL or list->size == 0, and false otherwise.

void FOS_list_free(FOS_List *list);

Releases all nodes and element buffers owned by the list.

After the call:

  • head == NULL
  • tail == NULL
  • size == 0
  • elem_size == 0

Calling the function with NULL is safe.

const void *FOS_list_at(const FOS_List *list, size_t pos);

Returns a pointer to the element at zero-based position pos.

Returns NULL if list is NULL, the list is empty, or pos is outside the list.

The returned pointer refers to list-owned storage.

The operation is O(n).

void *FOS_list_at_mut(FOS_List *list, size_t pos);

Returns a mutable pointer to the element at zero-based position pos.

Returns NULL if list is NULL or pos is outside the list.

The returned pointer refers to list-owned storage.

The operation is O(n).

bool FOS_list_remove_at(FOS_List *list, size_t pos);

Removes the element at zero-based position pos.

The corresponding node and element storage are released.

If pos == 0, the operation is equivalent to FOS_list_pop_front().

Removing an arbitrary position requires traversal and is O(n).

Returns true if an element was removed and false if the list is NULL, empty, or pos is outside the list.

bool FOS_list_set(FOS_List *list, size_t pos, const void *value);

Replaces the element at zero-based position pos by copying elem_size bytes from value.

The operation does not change the number or order of nodes.

Returns true on success and false if list or value is NULL, or if pos is outside the list.

const void *FOS_list_front(const FOS_List *list);

Returns a pointer to the first element.

Returns NULL if list is NULL or empty.

The operation is O(1).

const void *FOS_list_back(const FOS_List *list);

Returns a pointer to the last element.

Returns NULL if list is NULL or empty.

The operation is O(1).

size_t FOS_list_size(const FOS_List *list);

Returns the number of elements in the list.

Returns 0 if list is NULL.

The operation is O(1).

bool FOS_list_reverse(FOS_List *list);

Reverses the list in place by rearranging node links.

The element data is not copied.

Updates head and tail while preserving size and elem_size.

The operation is O(n).

Returns true on success and false if list is NULL or empty.

bool FOS_list_sort(FOS_List *list, int (*cmp_func)(const void *val1, const void *val2));

Sorts the list using cmp_func.

The sorting algorithm is stable merge sort.

Equal elements retain their original relative order.

The operation has O(n log n) time complexity and uses O(log n) auxiliary stack space.

The list nodes themselves are rearranged; no new nodes are allocated.

Returns true on success and false if list or cmp_func is NULL.

An empty list or a list containing one element is considered successfully sorted.

void FOS_list_foreach(const FOS_List *list, void (*func)(const void *item, void *user), void *user);

Calls func once for every element, beginning with the first element and continuing toward the tail.

The callback receives the element through a const pointer.

Returns immediately if list or func is NULL.

void FOS_list_foreach_mut(FOS_List *list, void (*func)(void *item, void *user), void *user);

Calls func once for every element, beginning with the first element and continuing toward the tail.

The callback receives a mutable pointer to the element and may modify it.

Returns immediately if list or func is NULL.

static inline int FOS_list_cmp_int(const void *val1, const void *val2);

Example comparison function for sorting lists of int.

Returns:

  • a negative value if the first integer is less than the second;
  • zero if the integers are equal;
  • a positive value if the first integer is greater than the second.

The function is provided as a convenience example for FOS_list_sort().
