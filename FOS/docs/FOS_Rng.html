FOS_Rng

The FOS_Rng module provides pseudo-random number generation based on the PCG32 (Permuted Congruential Generator) algorithm.

The generator uses a 64-bit internal state and stream increment and produces 32-bit pseudo-random values with a good statistical distribution.

The module is intended for general-purpose randomness such as simulations, games, procedural generation, randomized algorithms, and testing.

It is not intended for cryptographic use.

There are two files:

  • FOS_Rng.h is the public header intended to be included by user code.
  • FOS_Rng.c contains the implementation and is included in source distributions.

FOS_Rng representation

FOS_Rng contains:

  • state, the 64-bit internal generator state;
  • inc, the stream increment.

The state is advanced every time a random value is generated.

The generator uses the PCG32 XSH-RR output transformation.

Multiple independently initialized FOS_Rng objects can be used at the same time. The generator is stored entirely in the FOS_Rng object and does not require dynamically allocated memory.

Seeding and streams

FOS_rng_seed() initializes a generator from a user-supplied seed and stream.

The stream value is converted into an odd internal increment:

inc = (stream << 1) | 1

Two generators initialized with the same seed and stream produce the same sequence of values.

Changing the seed or stream produces a different generator state and is intended to provide an independent sequence.

FOS_rng_default() returns a generator initialized with fixed predefined state and stream values. It is deterministic and therefore produces the same sequence each time it is called.

FOS_rng_seed_auto() generates initialization values using a combination of a thread-local counter, the current time, and addresses of local objects. It is intended as a convenient source of non-deterministic initialization values for ordinary applications.

The automatically generated seed is not suitable for cryptographic purposes.

Integer generation

32-bit values

FOS_rng_u32() returns a uniformly distributed 32-bit value over the full range representable by uint32_t:

[0, UINT32_MAX]

Each call advances the generator state.

64-bit values

FOS_rng_u64() constructs a 64-bit pseudo-random value from two successive 32-bit generator outputs.

It returns a value over:

[0, UINT64_MAX]

Integer ranges

FOS_rng_range_gen() generates a pseudo-random uint32_t within an inclusive range:

[min, max]

If min > max, the values are swapped automatically.

FOS_rng_range_gen_u64() provides the same behavior for uint64_t.

The range functions use rejection sampling to avoid modulo bias.

When the requested range covers the entire integer type, the corresponding full-width generator is used directly.

Examples:

FOS_rng_range_gen(rng, 1, 6)
    -> one of 1, 2, 3, 4, 5, 6

FOS_rng_range_gen_u64(rng, 0, 99)
    -> one of 0 through 99

A range containing a single value always returns that value.

Default range generator

FOS_rng_range() is a convenience function that uses an automatically initialized thread-local generator.

The generator is initialized on the first call in each thread.

Subsequent calls in the same thread continue the same pseudo-random sequence.

The function generates values in the inclusive range:

[min, max]

and swaps min and max when min > max.

Because the generator is thread-local, each thread has its own generator state.

Floating-point generation

FOS_rng_f64() generates a double in the half-open interval:

[0.0, 1.0)

The generated value is based on 53 random bits, matching the significand precision used by an IEEE 754 binary64 double.

The value can be used for generating uniformly distributed floating-point parameters in applications where the limitations of floating-point representation are acceptable.

Shuffling

FOS_rng_shuffle_int() shuffles the contents of an int array in place.

The implementation uses the Fisher-Yates shuffle and selects each exchange index using the range generator.

The resulting permutation is generated without modulo bias.

FOS_rng_shuffle_generic() performs the same operation on an array of arbitrary fixed-size elements.

The generic version uses elem_size bytes per element and temporarily allocates one element-sized buffer through the FOS allocator.

Neither function allocates new array storage.

Both functions modify the supplied array in place.

Random selection

FOS_rng_choose() selects one element from an array without modifying it.

The function returns a pointer to the selected element:

index ∈ [0, n - 1]

The returned pointer refers directly to the supplied array.

The caller retains ownership of the array and must ensure that the array remains valid while the returned pointer is used.

Complexity

The basic generator operations have constant time complexity:

FOS_rng_u32()             O(1)
FOS_rng_u64()             O(1)
FOS_rng_range_gen()       O(1) expected
FOS_rng_range_gen_u64()   O(1) expected
FOS_rng_range()           O(1) expected
FOS_rng_f64()             O(1)
FOS_rng_choose()          O(1)

The range functions use rejection sampling, so their worst-case running time is unbounded in principle, although the expected running time is constant.

Shuffling an array of n elements takes:

O(n)

time.

The generic shuffle additionally requires temporary storage of elem_size bytes.

Functions

FOS_Rng FOS_rng_default(void);

Returns a deterministically initialized FOS_Rng using predefined internal state and stream values.

Calling the function repeatedly produces generators with identical initial states and therefore identical output sequences.

Useful when reproducible pseudo-random sequences are desired.

FOS_Rng FOS_rng_seed(uint64_t seed, uint64_t stream);

Initializes a generator using the supplied seed and stream values.

The stream determines the generator's internal increment.

Two generators initialized with the same seed and stream produce the same sequence.

Returns the initialized generator by value.

FOS_Rng FOS_rng_seed_auto(void);

Initializes a generator using automatically generated initialization values.

The implementation combines a thread-local counter, the current time, and addresses of local objects.

This function is intended for convenient initialization in ordinary applications.

It does not provide cryptographically secure randomness.

Returns an initialized generator by value.

uint32_t FOS_rng_u32(FOS_Rng *rng);

Generates the next 32-bit pseudo-random value and advances rng.

Returns a value in:

[0, UINT32_MAX]

The caller must provide a valid, non-NULL FOS_Rng pointer.

uint32_t FOS_rng_range_gen(FOS_Rng *rng, uint32_t min, uint32_t max);

Generates a pseudo-random value in the inclusive range [min, max].

If min > max, the arguments are swapped.

The function uses rejection sampling to avoid modulo bias.

If the range contains exactly one value, that value is returned.

uint32_t FOS_rng_range(uint32_t min, uint32_t max);

Generates a pseudo-random value in the inclusive range [min, max] using an automatically initialized thread-local generator.

If min > max, the arguments are swapped.

Unlike FOS_rng_range_gen(), this function does not require an explicit FOS_Rng object.

uint64_t FOS_rng_u64(FOS_Rng *rng);

Generates the next 64-bit pseudo-random value using two successive 32-bit outputs.

Returns a value in:

[0, UINT64_MAX]

uint64_t FOS_rng_range_gen_u64(FOS_Rng *rng, uint64_t min, uint64_t max);

Generates a pseudo-random value in the inclusive range [min, max].

If min > max, the arguments are swapped.

The function uses rejection sampling to avoid modulo bias.

If the range contains exactly one value, that value is returned.

double FOS_rng_f64(FOS_Rng *rng);

Generates a pseudo-random double in the half-open interval [0.0, 1.0).

The result is constructed from 53 random bits.

bool FOS_rng_shuffle_int(int *arr, size_t n, FOS_Rng *rng);

Shuffles n elements of an int array in place using the Fisher-Yates algorithm.

Returns true on success.

Returns false if:

  • arr == NULL;
  • rng == NULL;
  • n == 0;
  • n > UINT32_MAX.

bool FOS_rng_shuffle_generic(void *data, size_t n, size_t elem_size, FOS_Rng *rng);

Shuffles an array of n elements in place using the Fisher-Yates algorithm.

Each element occupies elem_size bytes.

The function allocates one temporary buffer of elem_size bytes through FOS_alloc().

Returns true on success.

Returns false if:

  • data == NULL;
  • rng == NULL;
  • n == 0;
  • elem_size == 0;
  • allocation of the temporary buffer fails.

void *FOS_rng_choose(void *data, size_t n, size_t elem_size, FOS_Rng *rng);

Selects one element uniformly from an array of n elements.

Each element occupies elem_size bytes.

Returns a pointer to the selected element without modifying the array.

Returns NULL if:

  • data == NULL;
  • rng == NULL;
  • n == 0;
  • elem_size == 0.
