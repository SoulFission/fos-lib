FOS_String

The FOS_String module provides dynamically allocated strings with explicit size and capacity, together with lightweight non-owning string slices.

FOS_String stores owned character data. FOS_Slice refers to an existing sequence of characters without taking ownership of it.

The module operates on byte sequences and does not currently provide Unicode or encoding-aware string operations.

There are two files:

  • FOS_String.h is the public header intended to be included by user code.
  • FOS_String.c contains the implementation and is included in source distributions.

FOS_String representation

A FOS_String contains:

  • str, a pointer to storage owned by the string;
  • size, the number of characters currently stored;
  • capacity, the total number of bytes allocated for the string.

A valid FOS_String satisfies:

  • str != NULL
  • size < capacity
  • str[size] == '\0'

The terminating null character is part of the allocated storage but is not included in size.

The string may contain embedded null characters. size, rather than strlen(), determines the logical length of the string.

The default capacity used by FOS_str_new() is FOS_DEFAULT_CAPACITY, which is 64.

FOS_Slice representation

A FOS_Slice contains:

  • data, a pointer to the first character of the slice;
  • size, the number of characters in the slice.

A slice does not own its character data.

The lifetime of a slice's data is therefore controlled by the object from which the slice was obtained.

A slice may refer to a string, a C string literal, an array, or another compatible character buffer.

A valid slice has:

data != NULL

An empty slice may have size == 0.

Unlike FOS_String, a slice is not required to be null-terminated.

Ownership and value semantics

FOS_String functions generally return strings by value. These returned objects contain independently allocated character storage.

The pointer contained in a FOS_String is an owned resource. Copying an initialized FOS_String with structure assignment, memcpy(), or another shallow copy operation duplicates the pointer rather than the character data and can result in multiple objects attempting to release the same allocation.

Use FOS_str_copy() when an independent copy of an existing FOS_String is required.

Functions such as FOS_str_concat(), FOS_str_append_slice(), FOS_str_replace(), FOS_str_reverse(), and FOS_str_trim() return newly allocated strings and do not modify their source string.

FOS_Slice is a non-owning value type and may be copied freely. Copying a slice does not copy its character data.

String and slice conversion

FOS_str_as_slice() creates a non-owning slice referring to the contents of a FOS_String.

The returned slice remains valid only while the referenced string storage remains valid and is not reallocated.

FOS_slice_to_str() creates a new owned string containing a copy of the slice.

FOS_slice_from_cstr() creates a slice referring directly to an existing null-terminated C string. The C string is not copied or owned.

Capacity and growth

FOS_String maintains separate logical size and allocated capacity.

The capacity always includes room for the terminating null character.

FOS_str_grow() doubles the current capacity.

FOS_str_reserve() ensures that the requested capacity is available without changing the logical size.

Neither operation changes the string's contents.

The string must retain at least one byte beyond size so that the terminating null character can be stored.

Searching and comparison

The search functions operate on byte sequences rather than null-terminated strings.

FOS_slice_find_ch() searches a slice for a character.

FOS_slice_find_subslice() searches a slice for another slice using the Knuth-Morris-Pratt (KMP) algorithm.

FOS_str_find_substr() performs the same operation on FOS_String values.

Search functions return SIZE_MAX when the requested item is not found or when the operation cannot be performed because of invalid arguments or an allocation failure.

FOS_slice_cmp() performs lexicographical byte comparison.

If the common prefix compares equal, the shorter slice compares as smaller.

String modification

Operations returning FOS_String create new strings rather than modifying their input.

This includes:

  • FOS_str_append_slice()
  • FOS_str_concat()
  • FOS_str_replace()
  • FOS_str_reverse()
  • FOS_str_trim()

The original string remains unchanged.

FOS_str_reserve() and FOS_str_grow() are the exceptions: they operate directly on an existing FOS_String and may reallocate its storage.

Any slice referring to a string becomes invalid if the string's storage is released or moved by reallocation.

Joining and splitting

FOS_str_join() creates a new string containing an array of slices separated by a supplied separator slice.

FOS_slice_split_ch() divides a slice at occurrences of a specified character.

The resulting FOS_SliceArray owns only the array of FOS_Slice structures. The character data referenced by those slices remains owned by the original source.

Splitting preserves empty fields, including empty fields at the beginning or end of the source.

FOS_slice_array_free() releases the array of slice descriptors but does not release the character data referenced by them.

Trimming and tokenization

FOS_str_trim() returns a new string with leading and trailing whitespace removed.

FOS_slice_trim() returns a non-owning slice containing the same data with leading and trailing whitespace excluded.

Whitespace is determined using the C library isspace() classification.

FOS_slice_next_token_trimmed() extracts the next separator-delimited token from an input slice, trims whitespace from the token, and advances the input slice.

Leading separator characters are skipped.

Empty tokens produced by consecutive separators are therefore not returned.

Printing

The module provides functions for printing both strings and slices to standard output or to a specified FILE stream.

Unlike FOS_String, a FOS_Slice does not need to be null-terminated for printing because its explicit size determines how many characters are written.

The functions return the number of characters processed on success.

SIZE_MAX is returned when the argument or output stream is invalid or when a newline operation reports EOF.

Complexity

Simple front-to-back operations such as conversion to a slice, validity checks, and size/capacity access are O(1).

Character search using FOS_slice_find_ch() is O(n).

Substring search using KMP is O(n + m) where n is the haystack size and m is the needle size.

Comparison of two slices is O(min(n, m)).

Concatenation, joining, replacement, reversing, and trimming require processing the affected character data and are O(n) in the size of the result or input.

Splitting a slice is O(n).

Reallocation performed by growth or reserve operations may require O(n) time when the underlying allocation is moved.

Functions

FOS_String FOS_str_new(void);

Creates an empty string with FOS_DEFAULT_CAPACITY bytes of storage.

The logical size is zero and the string is null-terminated.

Returns a zero-initialized FOS_String if allocation fails.

FOS_String FOS_str_new_cpc(size_t capacity);

Creates an empty string with capacity bytes of storage.

The logical size is zero and the string is null-terminated.

capacity must be nonzero.

Returns a zero-initialized FOS_String if capacity == 0 or allocation fails.

FOS_String FOS_str_copy(FOS_String src);

Creates an independent copy of src.

The new string receives its own allocation with the same logical size and capacity as src.

Returns a zero-initialized FOS_String if src is invalid or allocation fails.

FOS_String FOS_str_from_cstr(const char *cstr);

Creates an owned string from a null-terminated C string.

The contents of cstr, including its terminating null character, are copied.

The initial capacity is at least FOS_DEFAULT_CAPACITY, or large enough to hold the source string and its terminator.

Returns a zero-initialized FOS_String if cstr is NULL or allocation fails.

char *FOS_str_cstr(FOS_String fos_str);

Creates a newly allocated null-terminated C string containing the logical contents of fos_str.

The returned pointer is independently allocated and must be released by the caller using the active FOS allocator.

Returns NULL if the string is invalid, its size cannot be represented for the required allocation, or allocation fails.

void FOS_str_free(FOS_String *fos_str);

Releases the character storage owned by fos_str.

The string is reset to:

str == NULL
size == 0
capacity == 0

Calling the function with NULL is safe.

FOS_Slice FOS_str_as_slice(FOS_String fos_str);

Creates a non-owning slice referring to the logical contents of fos_str.

No character data is copied.

The returned slice becomes invalid if the string is freed or its storage is reallocated.

FOS_Slice FOS_slice_from_cstr(const char *cstr);

Creates a non-owning slice referring to a null-terminated C string.

The C string is not copied.

Returns a zero-initialized slice if cstr is NULL.

FOS_Slice FOS_slice_sub(FOS_Slice fos_slc, size_t pos, size_t len);

Creates a non-owning subslice beginning at pos and extending for at most len characters.

If len extends beyond the end of the slice, it is truncated to the remaining number of characters.

pos may equal fos_slc.size, producing an empty slice.

Returns a zero-initialized slice if the source slice is invalid or pos is outside the slice.

size_t FOS_slice_find_ch(FOS_Slice fos_slc, int ch);

Searches the slice for the first occurrence of ch.

Returns the zero-based position of the first matching character.

Returns SIZE_MAX if the slice is invalid or the character is not found.

size_t FOS_slice_find_subslice(FOS_Slice haystack, FOS_Slice needle);

Searches haystack for the first occurrence of needle using the Knuth-Morris-Pratt algorithm.

Returns the zero-based position of the first occurrence.

Returns SIZE_MAX if either slice is invalid, needle is empty, needle is longer than haystack, allocation of the KMP table fails, or the needle is not found.

size_t FOS_str_find_substr(FOS_String haystack, FOS_String needle);

Searches haystack for the first occurrence of needle using the Knuth-Morris-Pratt algorithm.

Returns the zero-based position of the first occurrence.

Returns SIZE_MAX if either string is invalid, needle is empty, needle is longer than haystack, allocation of the KMP table fails, or the substring is not found.

int FOS_slice_cmp(FOS_Slice a, FOS_Slice b);

Lexicographically compares two slices as byte sequences.

The common prefix is compared first. If the common prefix is equal, the shorter slice compares as smaller.

Requires valid slices.

Returns a negative value if a < b, zero if a == b, and a positive value if a > b.

bool FOS_slice_valid(FOS_Slice fos_slc);

Checks whether a slice has a non-NULL data pointer.

Returns true if fos_slc.data != NULL, false otherwise.

bool FOS_string_valid(FOS_String fos_str);

Checks whether a string has allocated storage.

Returns true if fos_str.str != NULL, false otherwise.

FOS_String FOS_slice_to_str(FOS_Slice fos_slc);

Creates a new owned string containing a copy of the slice.

The resulting string is null-terminated and has enough capacity for its contents and terminator, with a minimum capacity of FOS_DEFAULT_CAPACITY.

Returns a zero-initialized string if the slice is invalid or allocation fails.

bool FOS_str_grow(FOS_String *fos_str_ptr);

Doubles the current capacity of the string.

If the existing capacity is zero, FOS_DEFAULT_CAPACITY is used.

The logical contents remain unchanged.

Returns false if the argument is invalid, the new capacity would overflow, or reallocation fails.

bool FOS_str_reserve(FOS_String *fos_str_ptr, size_t to_reserve);

Ensures that the string has at least to_reserve bytes of capacity.

The logical size and contents are unchanged.

The requested capacity must be sufficient to hold the current contents and their terminating null character.

Returns true if the requested capacity is already available or if the storage is successfully reallocated.

Returns false for invalid arguments, insufficient requested capacity, an overflow condition, or allocation failure.

FOS_String FOS_str_append_slice(FOS_String fos_str, FOS_Slice tail);

Creates a new string containing fos_str followed by tail.

The source string and slice are not modified.

Returns a zero-initialized string if either input is invalid or the resulting size cannot be represented or allocated.

FOS_String FOS_str_join(const FOS_Slice parts[], size_t count, FOS_Slice sep);

Creates a new string by concatenating count slices with sep inserted between adjacent parts.

The input slices are not modified.

Returns a zero-initialized string if parts is NULL, count == 0, sep is invalid, an input part is invalid, an overflow occurs, or allocation fails.

size_t FOS_slice_print(FOS_Slice fos_slc);

Writes the characters of fos_slc to standard output.

Returns the number of characters processed, or SIZE_MAX if the slice is invalid.

size_t FOS_slice_println(FOS_Slice fos_slc);

Writes the slice to standard output followed by a newline.

Returns the number of characters processed including the newline, or SIZE_MAX on failure.

size_t FOS_str_print(FOS_String fos_str);

Writes the logical contents of fos_str to standard output.

Returns the number of characters processed, or SIZE_MAX if the string is invalid.

size_t FOS_str_println(FOS_String fos_str);

Writes the logical contents of fos_str followed by a newline.

Returns the number of characters processed including the newline, or SIZE_MAX on failure.

size_t FOS_slice_fprint(FOS_Slice s, FILE *stream);

Writes the characters of s to stream.

The slice does not need to be null-terminated.

Returns the number of characters processed, or SIZE_MAX if the slice or stream is invalid.

size_t FOS_slice_fprintln(FOS_Slice fos_slc, FILE *stream);

Writes the slice to stream followed by a newline.

Returns the number of characters processed including the newline, or SIZE_MAX on failure.

size_t FOS_str_fprint(FOS_String fos_str, FILE *stream);

Writes the logical contents of fos_str to stream.

Returns the number of characters processed, or SIZE_MAX if the string or stream is invalid.

size_t FOS_str_fprintln(FOS_String fos_str, FILE *stream);

Writes the logical contents of fos_str to stream followed by a newline.

Returns the number of characters processed including the newline, or SIZE_MAX on failure.

FOS_String FOS_str_concat(FOS_String s1, FOS_String s2);

Creates a new string containing s1 followed by s2.

Neither source string is modified.

Returns a zero-initialized string if either input is invalid, the resulting size cannot be represented, or allocation fails.

FOS_String FOS_str_replace(FOS_String src, FOS_Slice needle, FOS_Slice replacement);

Creates a new string in which the first occurrence of needle in src is replaced with replacement.

The source string is not modified.

If needle is not found, an independent copy of src is returned.

Returns a zero-initialized string if an argument is invalid, an overflow occurs, or allocation fails.

FOS_SliceArray FOS_slice_split_ch(FOS_Slice src, int ch);

Splits src at occurrences of ch.

The result contains one slice for every field, including empty fields.

The returned FOS_SliceArray owns the array of slice descriptors but does not own the character data referenced by those slices.

Returns a zero-initialized array if src is invalid, the required allocation cannot be represented, or allocation fails.

void FOS_slice_array_free(FOS_SliceArray *arr);

Releases the array of slice descriptors owned by arr.

The character data referenced by the slices is not released.

The structure is reset to:

data == NULL
size == 0

Calling the function with NULL is safe.

FOS_String FOS_str_reverse(FOS_String fos_str);

Creates a new string containing the characters of fos_str in reverse order.

The source string is not modified.

Returns a zero-initialized string if the source is invalid or allocation fails.

This operation reverses bytes; it does not account for Unicode code points or multibyte character encodings.

FOS_String FOS_str_trim(FOS_String fos_str);

Creates a new string with leading and trailing whitespace removed.

Whitespace is determined using the C library isspace() classification.

The source string is not modified.

Returns a zero-initialized string if the source is invalid or allocation fails.

bool FOS_slice_starts_with(FOS_Slice s, FOS_Slice prefix);

Checks whether s begins with prefix.

Returns true if prefix is a prefix of s, false otherwise.

An empty non-NULL prefix matches any valid slice.

bool FOS_slice_ends_with(FOS_Slice s, FOS_Slice suffix);

Checks whether s ends with suffix.

Returns true if suffix is a suffix of s, false otherwise.

An empty non-NULL suffix matches any valid slice.

FOS_Slice FOS_slice_trim(FOS_Slice s);

Returns a non-owning subslice with leading and trailing whitespace removed.

Whitespace is determined using the C library isspace() classification.

No character data is copied.

Returns a zero-initialized slice if s is invalid.

bool FOS_slice_eq(FOS_Slice a, FOS_Slice b);

Checks whether two slices contain identical byte sequences.

Returns true if their sizes are equal and their contents compare equal.

Returns false if either slice is invalid or their sizes differ.

FOS_Slice FOS_slice_next_token_trimmed(FOS_Slice *input, int sep);

Extracts the next token from input, using sep as the separator.

Leading separator characters are skipped.

The resulting token is trimmed of leading and trailing whitespace.

The input slice is advanced so that subsequent calls continue from the remaining input.

Consecutive separators are skipped and therefore do not produce empty tokens.

Returns a zero-initialized slice when input is NULL, the input slice is invalid, or no token remains.

The returned slice does not own its character data.
